# 杉木经营账本

一个纯离线、单文件的经营记账工具，适合个人或家庭小规模的杉木地块经营。它按地块整理承包款、支出、工人工资、运输费用、卖木收入和待收尾款，并自动计算投入、收入、成本和利润。

## 功能

- 新建和管理多个杉木地块，记录地点、山主、合同、面积、承包款和定金
- 记录油费、材料、办证、维修等日常支出
- 记录工人工资、机械费用和外部运输费用，区分应付与已付金额
- 记录每车木的买家、方量、单价、应收总价和已收金额，自动显示待收尾款
- 查看项目总投入、总收入、账面盈亏、实际盈亏、年度小结和月度账目
- 按地块保存现场照片、视频和其他文件，并填写现场说明
- 支持经营者信息、中文/English 界面、打印和表格导出
- 支持 JSON 备份与恢复

## 使用方法

1. 打开 [`index.html`](./index.html)，无需安装服务器或数据库。
2. 新建一个地块，填写项目和合同信息。
3. 按实际发生情况记录支出、工资、运输、卖木收入和收款。
4. 在“查账”中查看成本、收入、利润和欠款。
5. 定期在“设置”中导出 JSON 备份；换电脑或浏览器时可以导入备份。

## 数据与隐私

这是一个本地离线工具。文字数据保存在浏览器 `localStorage`，照片、视频和文件保存在浏览器 IndexedDB，不会自动上传到服务器。清理浏览器数据、使用隐私模式或更换浏览器前，请先导出备份。
